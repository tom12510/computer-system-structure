多维随机变量及其概率分布

  • 二维随机变量

假设E是随机试验，\Omega是样本空间，X，Y是定义在\Omega的随机变量

分布函数： $$ F(x,y) = P{X\le x,Y\le y} 关于X，Y联合分布函数 $$ 分布函数性质：

  1. 0\le F(x,y) \le 1
  2. F(x,y) 当y不变 x_1\le x_2时 F(x_1,y)\le F(x_2,y)
  3. F(-\infty,y)=0,F(x,-\infty)=0,F(-\infty,-\infty)=0，F(+\infty,+\infty)=1
  4. P\{x_1<X\le x_2，y_1<Y\le y_2\} =F(x_2,y_2)-F(x_2,y_1)-F(x_1,y_2)+F(x_1,y_1) \ge 0

关于X、Y的边缘分布：横纵求和

二维连续分布函数与密度函数关系 $$ f(s,t)为联合密度函数 \ \F(x,y) =P{X\le x，Y\le y} = \int_{-\infty}^x \int_{-\infty}^yf(s,t)dsdt $$

  • 二维边缘分布函数 $$ 变量X取定点x，变量Y取任意值，得到对X的边缘分布函数 F_X(x) \ \ F_X(x) = P{X \le x } = F(x,+\infty) = P{X\le x , Y \le +\infty } ~~F_X(x)：X的边缘 分布函数 \ \ F_Y(y) = P{Y \le y } = F(+\infty,y) = P{X\le \infty , Y \le y } ~~F_X(x)：X的边缘 \ $$

  • 二维边缘密度函数与联合密度函数 $$ f_X(x) = \int_{-\infty}^{+\infty}f(x,t)dt = \int_{-\infty}^{+\infty}f(x,y)dy \ \ f_Y(x) = \int_{-\infty}^{+\infty}f(s,y)dt = \int_{-\infty}^{+\infty}f(x,y)dx $$

  • 二维均匀分布 $$ 当D是矩形时：f(x,y)= \begin{cases} \frac{1}{(b-a)(d-c)} ~~~ a\le x \le b , c\le y \le d \ 0 ~~~~~~ 其他 \end{cases} \ 当D是圆形区域时： f(x,y) = \begin{cases} \frac{1}{\pi R^2} ~~~~ x^2 +y^2\le R^2 \ 0 ~~~~~~~~~其他 \end{cases} $$
